# Fashion PDF Studio — Vrisama AI Careers

Save public website guides, fashion trend references and supplier pages to PDF, with optional offline MHTML archives.

## Windows setup
1. Install Python 3.10+ from https://www.python.org/downloads/ and check **Add Python to PATH**.
2. Download START_WINDOWS.cmd and save it in its own folder.
3. Right-click the file and inspect it in Notepad if Windows warns.
4. Double-click the launcher. It fetches app.py from this site and installs Playwright and pypdf.
5. The browser opens to http://127.0.0.1:8765 . Enter your URL and select Smart, Full page, All sections or Linked pages.
6. If Chrome/Edge is missing, run `py -3 -m playwright install chromium`.

The app runs locally and costs no API fees. Hosted GitHub Pages cannot run Python or headless browsers, so the actual conversion happens on your own computer. Some JavaScript-heavy, login-only, or restricted websites may need manual handling. Respect copyright and website access rules.
